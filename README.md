# 미술사연구회 출판부 도구

『미술사연구』 편집에 쓰는 웹 도구 모음입니다. GitHub Pages로 게시합니다.

## 원고 문자 검사

**주소: https://pudgala-appraiser.github.io/misulsayeongu/char-check/**

화면에서는 표준 문자와 똑같이 보이지만, 인쇄하면 다른 글꼴로 찍히거나 깨지는 문자를 문자 코드로 찾아냅니다. 기계적으로 고칠 수 있는 글자는 고친 수정본을 새 파일로 만들어 줍니다.

- 원고 파일은 브라우저 안에서만 읽고 고칩니다. 어디에도 올라가지 않습니다.
- 받는 파일: hwp, hwpx, docx, txt
- hwp는 검사만 합니다. 한글에서 hwpx로 저장해 올리면 수정본까지 만들 수 있습니다.

### 쓰는 순서
1. 최초 제출 원고를 올린다.
2. **수정본 저장**으로 자동 수정한 파일을 받고, **직접 확인** 항목은 한글에서 고친다.
3. 수정본을 열어 이상 없는지 확인한 뒤 교정을 시작한다. **업체 전달** 목록은 1차 교정 때 업체에 넘긴다.

### 판정 기준
『미술사연구』 50호(2026년 6월) 최종 PDF 전수 조사(2026.10)가 근거입니다. 이 조사에서 업체 글꼴에 없는 글자 212종이 다른 글꼴로 찍혔고, 한글 전용 겹낫표 114자, 반각 낫표 69자, 강희부수 문자 21자가 그대로 인쇄됐습니다. 꺾쇠는 `<>` 약 180쌍과 `〈〉` 175쌍이 섞인 채 실렸고(업체 글꼴 윤명조에서는 같은 모양으로 찍힘), 수학 기호 `≪≫`는 부등호 모양으로 찍혔습니다.

| 처리 | 대상 |
|---|---|
| 자동 수정 | 비표준 가운뎃점(‧ ․ ㆍ ∙ ⋅ · ・ → ·), 강희부수 문자(U+2F00–2FDF → 같은 모양의 한자), 한글 전용 겹낫표(U+F0854·F0855 → 『』), 반각·세로쓰기용 낫표(｢｣ ﹁﹂ → 「」, ﹃﹄ → 『』), 짝이 맞는 꺾쇠(< > ＜ ＞ 〈〉(U+2329) ⟨⟩ ︿﹀ → 〈〉, ≪≫ << >> ⟪⟫ ︽︾ → 《》) |
| 직접 확인 | 일본어 문맥의 ・, 로마자 단어 안의 점(예: Asan·ga → Asaṅga), 조합형 발음 부호, 정체를 알 수 없는 한글 전용 문자, 이미 깨진 문자, « »(서양어 원문 인용이 아니면 《》), 짝 없는 ＜ ≪ 등 |
| 업체 전달 | KS X 1001 밖 한자(일본 신자체·중국 간체자·확장 한자·畫 등), 로마자 발음 구별 부호, 옛한글 |
| 지적 안 함 | 호환 한자(李 U+F9E1 등), 원문자, 결락자 □, 짝 없는 < >(수식·화살표) |

- 꺾쇠의 기준은 원고작성원칙 10-4항(〈〉 작품명, 《》 서화첩·병풍·전시회명)입니다. 표 번호도 〈표 1〉로 통일합니다.
- 꺾쇠는 같은 문단 안에서 짝이 맞을 때만 고칩니다. 앞에 로마자·숫자가 붙은 <(p<0.05), 닫는 꺾쇠 바로 뒤에 로마자가 붙은 것(a>b), 안에 = 이나 주소(://, @, www.)가 든 것, 글자가 없는 것, 80자보다 먼 짝은 고치지 않습니다. 안쪽이 공백으로 시작하거나 끝나면 한글·한자가 있을 때만 고칩니다.
- 옛한글 인용 안의 아래아는 건드리지 않습니다.
- 50호에서 대체 글꼴로 찍힌 한자 131종 중 130종이 KS X 1001 밖 글자였고, 정상 출력된 1,582종 중에는 하나도 없었습니다. 그래서 'KS X 1001 밖 한자'를 업체 전달 기준으로 씁니다.

### hwpx 수정본에 대해
글자 수가 달라지는 수정을 한 문단(전용 겹낫표 → 『』, << → 《 등)은 줄 배치 정보(linesegarray)를 지워, 한글이 열 때 배치를 다시 계산하게 합니다. 처음 몇 편은 수정본을 한글에서 열어 확인해 주세요.

## 관리

- 판정 규칙은 Claude 스킬 `manuscript-char-check`와 똑같이 유지합니다. **규칙을 바꾸면 이 저장소와 스킬을 함께 고칩니다.**
- 수정할 때는 `char-check/index.html`의 판 번호(바닥글)를 올립니다.
